Layout Approaches

Following shadcn design principles — clean, ordered, consistent

How should the page be organized?

A

Tabbed sections

Use shadcn Tabs to separate: Status / API Keys / Probes / Database. Each tab is focused and scannable. Delete DB gets its own clear home.

B

Stacked cards

Separate shadcn Cards for each concern — Status card, API Keys card, Probes card, Database card. Visual hierarchy through card spacing. Delete DB always visible at bottom.

C

Status card + Tabs for the rest

Backend/API status always visible at top as a card. Below that, Tabs for API Keys, Probes, and Database. Best of both — status at a glance, details on demand.
