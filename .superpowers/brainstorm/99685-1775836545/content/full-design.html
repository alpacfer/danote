Cache clearing behavior

The "Delete DB + Clear cache" button will:

  1. Delete the backend database via the existing API
  2. Clear localStorage and sessionStorage
  3. Unregister service workers + clear Cache API
  4. Run the existing runAppDatabaseResetWorkflow to reset app state
  5. Force a hard page reload (window.location.reload())
